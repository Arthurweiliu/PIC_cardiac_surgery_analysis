# PIC Cardiac Surgery Analysis

Analysis code and processed datasets for the study:

**Correcting Surgical Misclassification Refines Mortality Estimates in Pediatric Cardiac Surgery: A Pediatric Intensive Care Database Cohort Study**

## Overview

Retrospective cohort study of 2,235 children who underwent cardiac surgery at the Children's Hospital of Zhejiang University School of Medicine, using the publicly available PIC (Pediatric Intensive Care) database (2010–2018). The study quantifies misclassification bias arising from naive keyword-based surgical coding and provides corrected, procedure-specific perioperative outcome estimates based on a hierarchical classification approach.

**Key findings**

- Overall in-hospital mortality: 1.3% (30/2,235)
- 413 patients (18.5%) reclassified by hierarchical classification
- Isolated PDA closure mortality: 4.3% (naive) → 1.4% (corrected)
- TOF repair mortality: 3.3% (naive) → 3.6% (corrected)
- Neonatal age was the strongest factor associated with mortality (OR 54.5, 95% CI 13.3–324.3)

## Reproducibility

- **Software**: R ≥ 4.5 with packages `dplyr`, `tidyverse`, `ggplot2`, `cowplot`, `scales`, `logistf`, `pROC`
- **Pipeline**: run scripts in `code/` in numeric order; figures are generated by `make_figures_v3.R` and `generate_forest_plot.R`
- **Raw data**: PIC database (https://pic.nbscn.org/), available after registration; the derived analysis cohort is provided in `dataset/`

## Note

The manuscript is not included in this repository. The processed dataset and complete analysis code are provided to support reproducibility of the analyses.
